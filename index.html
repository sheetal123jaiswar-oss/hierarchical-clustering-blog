01 / The basics

What is Hierarchical Clustering?

Hierarchical clustering is an unsupervised learning algorithm that groups similar data points into a hierarchy. The relationships are often displayed using a tree-shaped diagram called a dendrogram. You can choose a cut level on the tree to decide the number of clusters.

🌱

Unsupervised

It discovers patterns without requiring pre-labelled target categories.

🌳

Tree structure

Clusters join or split at different levels, showing their relationships.

03 / How it works

Two approaches to building a hierarchy

⬆️

Agglomerative

Bottom-up approach. Start with each data point as its own cluster, then repeatedly merge the closest clusters.

⬇️

Divisive

Top-down approach. Start with all points in one cluster and repeatedly split groups into smaller ones.
