  <h2>What Have We Learned? 🌳</h2>
  <p>Hierarchical Clustering is an unsupervised machine learning technique that organizes similar data points into a tree-like structure. Its dendrogram helps us understand relationships between clusters and choose a suitable number of groups.</p>
  <p>It is useful in customer segmentation, biology, document grouping and many other fields. However, it can be computationally expensive for large datasets, and the results depend on the selected distance and linkage methods.</p>
  <p><b>Final takeaway:</b> Hierarchical Clustering helps us discover hidden patterns in data without needing predefined labels.</p>
